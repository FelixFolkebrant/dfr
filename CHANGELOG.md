# Changelog

All notable changes to DFR are documented in this file.

## Unreleased

### Added

- First-parent merge history with merged-branch and commit navigation.

### Changed

- Commit selection now uses a layered, Git-log-style menu with per-commit change totals.
- Merged-branch history now uses a newest-first list with branch statistics and tree navigation.

## 0.0.1 - 2026-07-05

### Added

- Pull-request-style branch comparisons using the branches' merge base.
- Whole-branch and commit-by-commit review scopes with commit navigation.
- Tree, flattened, and contextual changed-file views.
- File status and addition/deletion summaries.
- Native VS Code diffs for added, modified, deleted, and renamed files.
- Branch selection, configurable default base branch, refresh, loading, empty, and error states.
- Keyboard-accessible sidebar controls with VS Code theme integration.
