# Issue

### What?

IS-007: Open selected branch changes in VS Code's native diff editor.

This issue connects validated sidebar file selection to lazy merge-base and head file loading in the extension host, then presents those read-only versions with VS Code's built-in diff editor. It removes the third-party diff renderer and its webview while retaining explicit loading, binary, error, stale-selection, and branch-reset behavior.

### Acceptance criteria

- [x] Selecting a text file loads only that file's merge-base and head contents.
- [x] Modified, added, deleted, and renamed files open with the correct content on both sides of the comparison.
- [x] Text files render through VS Code's built-in `vscode.diff` command and read-only virtual documents.
- [x] Loading uses a native status-bar progress indicator; binary and error states use native VS Code notifications.
- [x] Results from stale comparisons or superseded selections are ignored.
- [x] Branch changes clear the selection, invalidate pending file loads, and close this extension's open diff tabs.
- [x] `@pierre/diffs`, the diff-panel webview, and its build output are removed.
- [x] Explicit refresh and caching remain out of scope.
- [x] Focused automated tests and all repository checks pass.

### Notes

- The summary's merge-base commit is reused when loading the base-side file, so the displayed comparison matches the sidebar summary.
- Added files use an empty base document, deleted files use an empty head document, and renamed files load the old and new canonical paths.
- The native editor owns syntax highlighting, unified/split presentation, accessibility, scrolling, and large-text rendering behavior.

# What has been built

Selecting a changed text file now loads that file's contents at the active comparison's merge base and head. The request includes status and both canonical paths for renames, uses empty content for the missing side of additions and deletions, and rejects results from superseded selections or comparisons.

The extension exposes the two versions as read-only virtual text documents and opens them with VS Code's built-in `vscode.diff` command. A native status-bar spinner reports loading, native notifications report binary files and failures, and changing branches closes only Branch Diff Review diff tabs. The third-party diff dependency and complete diff-panel webview surface have been removed.
