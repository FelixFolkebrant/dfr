# What has been built

The Branch Diff sidebar now renders the active comparison's changed paths with `@pierre/trees`. Folders start expanded, empty path segments are flattened, supported Git statuses use the tree's built-in status presentation, and each file row shows available addition/deletion counts or a binary marker.

Selecting a file sends its canonical path and comparison ID to the extension host. The sidebar controller verifies that the request still belongs to the active comparison and that the path exists in its summary before publishing the selected path. Switching branches creates a new tree and clears the prior selection, while stale comparison requests and unknown paths are ignored.

The third-party beta API is contained in a local `ChangedFileTree` component. The webview TypeScript target now uses bundler-style ESM resolution to match the existing esbuild pipeline and the library's ESM-only package.
