# Issue

### What

IS-023: Tighten sidebar spacing.

Reduce the padding above the branch/commit box and the spacing between the actions bar and Changes. Render commit details only when a commit is selected so an empty wrapper cannot add an extra gap.

### Acceptance criteria

- [x] The sidebar uses 6px top padding instead of 14px, including its initial loading state.
- [x] The ready All changes view uses one 8px gap between the actions bar and Changes instead of two 14px gaps.
- [x] Commit details contribute no layout element when no commit is selected.
- [x] Review sections use 8px gaps while selected commit messages, loading feedback, and errors remain available.

### Confirmation

#### Automated checks

- `pnpm check` on 2026-10-12: passed extension and webview TypeScript checks, Biome, all 42 tests, and production builds.
- `git diff --check`: passed.

#### Manual testing

Open this issue worktree in VS Code, run `pnpm install --frozen-lockfile`, and press F5 with **Run DFR Extension** selected. In the Extension Development Host, open a Git repository whose review branch has commits and changed files, then open DFR from the Activity Bar. Compared with the previous layout, the branch/commit box should start closer to the top and Changes should sit closer to the actions bar.

- [ ] **All changes:** Keep the branch scope selected. Confirm there is 6px of sidebar padding above the branch/commit box, one 8px gap below the actions bar before the Changes header row, and no blank Message area. The file list and view controls should remain visible.
- [ ] **Commit details:** Select a commit from the branch/commit dropdown. Confirm Message and its text appear between the actions bar and Changes, with 8px between review sections. Collapse and expand Message; confirm the text hides and returns. Select All changes again; confirm Message disappears and the single 8px gap returns.
- [ ] **Settings and history:** Open comparison settings and confirm both branch selectors remain usable below the actions bar. Close settings, open history, choose a merged branch if available, and confirm the commit box and Changes remain aligned without excess blank space. Close history to return to the current review.
- [ ] **Loading and empty:** Use comparison settings to choose branches, then compare a branch with itself. Confirm loading feedback remains visible while comparing and the empty result shows the no-commits and no-files messages without clipping.
- [ ] **Error:** Before starting the Extension Development Host, create a temporary branch with `git branch dfr-spacing-check HEAD`. Once DFR has loaded the branch list, delete that branch with `git branch -D dfr-spacing-check` without refreshing DFR. Open comparison settings, select the stale dfr-spacing-check entry as the review branch, and close settings. Confirm an error message remains visible between the actions bar and Changes. Choose an existing review branch to recover.
- [ ] **Responsive and keyboard:** Narrow the sidebar to about 200px, then widen it. Confirm controls and text remain usable without horizontal scrolling. Tab through the commit dropdown, action buttons, and Changes view buttons; use Enter or Space to activate them and confirm visible focus and expected selection behavior.
