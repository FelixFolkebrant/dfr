# Issue

### What?

IS-005: Show live branch comparison state in the sidebar.

This issue connects the extension-host Git backend to the sidebar webview. It provides branch selectors, marks the current branch, computes merge-base summaries when the selected refs change, and displays loading, empty, error, and summary states. Changed-file tree interaction, selected-file messages, patch rendering, and caching remain out of scope.

# What has been built

The Branch Diff sidebar now receives typed, serializable review state from the extension host. Running **Open Branch Diff Review** starts the initial merge-base comparison using the discovered repository, default base, and current branch while opening the existing review panel immediately.

Both native branch selectors are populated from the backend and mark the current branch with `•`. Changing either selection sends a validated request to the extension host, which recomputes the comparison and publishes its loading, ready, or error state. The webview performs no Git or filesystem work.

The ready state displays changed-file, addition, and deletion totals. A zero-file comparison has a dedicated empty message, Git failures remain visible beside usable selectors, and a request sequence prevents a slower prior comparison from overwriting a newer selection. The controller is separated from VS Code view lifecycle code so its state transitions can be tested directly.
