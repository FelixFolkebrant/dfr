# Issue

### What?

IS-024: Move review actions into the native title bar.

Experiment with Previous commit, Next commit, History, Copy hash, and Comparison settings beside Refresh in VS Code's DFR title bar. Remove their old row below the commit selector to give the review more vertical space.

### Acceptance criteria

- [x] All five actions use native title-bar commands with icons, tooltips, and a consistent order after Refresh.
- [x] Previous and Next retain the existing cycle through the oldest-first commit list and All changes.
- [x] Copy hash copies the full selected SHA and reports success in the VS Code status bar; it is disabled for All changes.
- [x] History and Comparison settings keep their existing sidebar content and mutually exclusive behavior, with Close icons and tooltips for open panels.
- [x] Navigation and copying are disabled before the sidebar mounts, during loading, for an empty commit list, and after comparison errors. Settings and History remain available after comparison errors.
- [x] The experiment is isolated from the original checkout and its uncommitted changes, with a concrete way to restore the previous installed layout.
- [ ] The reviewer approves the title-bar appearance, native keyboard interaction, and behavior at narrow sidebar widths.

#### Manual testing

From `/tmp/dfr-is-024`, run `pnpm install:local`, then run **Developer: Reload Window** in VS Code. Open `/home/felux/Documents/projects/dfr` and choose DFR in the Activity Bar. Use Refresh if repository discovery has not completed. For commit navigation, choose a review branch with at least two commits relative to its base in Comparison settings.

- [ ] **Initial appearance:** Hover over the DFR view title. Confirm Refresh is followed by Previous commit, Next commit, History, Copy hash, and Comparison settings. Confirm the old five-button row below the commit selector is gone, the selector still appears, and more vertical room is available for changed files.
- [ ] **Previous:** From All changes, click Previous. Confirm the newest commit is selected and its subject, counts, details, and changed files appear. Click repeatedly: confirm selection moves toward the oldest commit, then returns to All changes with branch totals.
- [ ] **Next:** From All changes, click Next. Confirm the oldest commit is selected. Click repeatedly: confirm selection moves toward the newest commit, then returns to All changes. Open the commit selector and choose a different commit; confirm native navigation continues from that selection.
- [ ] **Copy:** In All changes, confirm Copy hash is disabled. Select a commit, activate Copy hash, and paste into a scratch editor. Confirm the complete commit SHA is pasted and the status bar briefly shows `DFR: Commit hash copied`.
- [ ] **History:** Click History and confirm its icon changes to Close with the tooltip `DFR: Close history` and the merged-branch selector appears above the commit scope. Select a merged branch and confirm its comparison appears. Click History again and confirm the selector closes, the History icon returns, and the normal branch comparison returns.
- [ ] **Settings:** Click Comparison settings and confirm its icon changes to Close with the tooltip `DFR: Close comparison settings` and Review branch / Compare with replace the review content. Change the base and confirm the comparison reloads. Click it again and confirm the review returns with the chosen base. Open History and then Settings: confirm History closes. While reviewing a historical branch, open Settings: confirm DFR returns to the normal comparison before showing its settings. Open History from Settings and confirm Settings closes.
- [ ] **Loading and hiding:** Activate Refresh, or change a branch/base. During comparison loading, confirm Previous, Next, and Copy are disabled; after completion their enabled states match the selection. Switch to Explorer and back to DFR; confirm the comparison and open History/Settings state survive and the native Close icons match the open panel.
- [ ] **Empty:** In Settings, select the same branch for Review branch and Compare with, then close Settings. Confirm `No commits were introduced by this branch.` appears, and navigation and Copy are disabled while Settings and History remain usable. Restore the original base.
- [ ] **Error and recovery:** Create an unrelated temporary ref without switching the working branch using the commands below. Refresh DFR, then choose `dfr-toolbar-error` as Review branch while comparing against `main`. Close Settings. Confirm the comparison error is visible and Previous, Next, and Copy are disabled. Reopen Settings, restore the original review branch, and confirm the comparison loads and controls recover. Delete the temporary ref afterwards with `git branch -D dfr-toolbar-error`.

  ```sh
  toolbar_tree=$(git mktree < /dev/null)
  toolbar_commit=$(printf 'Toolbar error fixture\n' | git commit-tree "$toolbar_tree")
  git branch dfr-toolbar-error "$toolbar_commit"
  ```

- [ ] **Width and keyboard:** Resize the sidebar to roughly 220px and 400px. Hover/focus the title and confirm the native controls remain usable without overlapping the review content. Check the `…` menu for any overflow actions. Run **View: Focus on DFR View**, press Shift+Tab repeatedly until a view-title action is focused, and use Left/Right and Enter/Space to activate History and Settings. Confirm tooltips and focus indicators identify the focused action. Confirm the commit dropdown still supports its existing keyboard selection and Escape behavior.
- [ ] **Restore:** Run `code --install-extension /home/felux/Documents/projects/dfr/dfr.vsix --force`, then **Developer: Reload Window**. Confirm only Refresh remains in the title bar and the five-button row returns below the commit selector. To rebuild that original package from the untouched checkout, run `pnpm install:local` in `/home/felux/Documents/projects/dfr`. Reinstall `/tmp/dfr-is-024/dfr.vsix` to return to the experiment.
